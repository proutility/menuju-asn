# MENUJU ASN - CBT CAT SKD CPNS 2026 🏛️🚀

Platform Simulasi CBT & Live Battle Multiplayer Ujian SKD CPNS 2026 berbasis standar resmi BKN & KemenPAN-RB.

## Fitur Utama
1. **Standar Penilaian Resmi BKN**:
   - **TWK (Tes Wawasan Kebangsaan)**: Benar +5, Salah 0 (Passing Grade: 65).
   - **TIU (Tes Inteligensi Umum)**: Benar +5, Salah 0 (Passing Grade: 80).
   - **TKP (Tes Karakteristik Pribadi)**: Skala Berbobot 1 s.d. 5 (Passing Grade: 166).
   - Evaluasi kelulusan saklek: Wajib memenuhi ketiga ambang batas sekaligus.
2. **Real-Time Multiplayer Mabar**:
   - Room Code 5 digit instan.
   - Whitelist Email Tamu (Bypass akses Akun Free via Link Invite).
   - Live Leaderboard tie-breaker BKN: TKP desc -> TIU desc -> TWK desc -> Waktu tercepat.
3. **PWA Standalone**:
   - Ringan, responsif di HP Android/iOS dan Laptop Desktop.
   - Multi-tab offline persistence via Firebase.

## Backend & Arsitektur
- **Frontend**: Vanilla ES Modules, Modern CSS Grid & Flexbox, SweetAlert2.
- **Backend / Database**: Google Firebase Cloud Firestore (`cpns_*` namespacing) & Firebase Authentication.
- **Hosting**: GitHub Pages / Firebase Multi-Site Hosting.
